One funny line a hopeless tech support agent gives a desperate customer, for the [make.fun](https://make.fun/c/u-motasimfuad-have-you-tried-turning-it-off-154a938b) bounty "Have You Tried Turning It Off?".

> I know — let's turn it off and on again. It's the only tool I have left, and frankly, it's the only one that's never left me.

Run `node main.ts` — it writes the line to `/output/entry.txt` (125 characters, under the 199-character gate).
